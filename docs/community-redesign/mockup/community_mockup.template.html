      NEW · B2 filter bar

      One cohort definition, one set of filters, every panel. Cohort = QC standard × instrument model × track (DIA/DDA) × LC and gradient × amount. Evosep runs are named by a real Evosep method ("Evosep 60 SPD"). nanoLC runs are named by the run length recorded with the file plus the stored SPD ("44 min run (~38 SPD)"). A run with no LC recorded joins the nanoLC cohort for its SPD when that SPD is not an Evosep method; at an Evosep-method SPD it is listed but not ranked, because it could be either. Before, the page bucketed throughput four ways and amount three ways, so a 60 SPD timsTOF HT at 50 ng had a different n in every panel (606, 617, 1,341 or the whole family). The DIA/DDA switch moved here from the bottom of the page, and there is no mixed "All" view. The PEG section below is not affected, as today.

      Three steps

      1. Install STAN and run Pierce HeLa as your QC standard.Thermo 88328 (20 µg) or 88329 (5 × 20 µg), 50 ng per injection. Install guide
      2. Claim your lab name.Run stan community-claim (STAN 1.2+) and enter the 6-digit code we email you (it comes from noreply@stan-proteomics.org; check spam). An unclaimed name can be taken by anyone.
      3. Turn sharing on.Set community_submit: true in ~/.stan/community.yml, or send what you already have with stan submit-all.

      Your runs appear after the nightly rebuild at 04:00 UTC. They are searched with the pinned engines and frozen libraries described under Methods, so they compare directly with every other run here.

      What leaves your lab, and what is published

      Published, per QC run

      • Your lab pseudonym
      • Run date, submission time and ID
      • Instrument model and family, acquisition track
      • LC system, SPD and run length
      • QC standard and amount loaded
      • Column vendor and model, if you set them
      • Precursor, peptide, protein and PSM counts
      • Mass accuracy, peak width, points per peak, peak capacity
      • MS1/MS2 signal and dynamic range
      • A binned total-ion chromatogram (retention-time bins and intensities)
      • Missed-cleavage rate and median CV, when measured
      • IPS, community score, cohort ID, library coverage
      • STAN, DIA-NN and schema versions; FASTA and library checksums

      Sent, but never published

      • The file nameUsed only to catch duplicate submissions and amount typos, and to let you update a run. Whatever your naming scheme puts in it (initials, project codes) reaches the server, so keep that in mind.
      • Your email addressUsed once, to send the claim code. Only a peppered one-way hash is stored, in the public claims file.

      Never leaves your lab

      • Raw data and spectra
      • Search results beyond the summary numbers listed here
      • Instrument serial numbers
      • Sample, customer or project names, except as far as they appear in your file names

      Search: one frozen parameter set per track (v1.0.0)

      DIA · DIA-NN 2.3.0

      Search
      Library search against the vendor's empirical HeLa library (below) and the frozen FASTA
      Digest
      Trypsin (after K or R), 1 missed cleavage, peptides 7–30 residues
      Charge
      Precursor charge 2–4
      FDR
      Precursor q ≤ 0.01; protein-group q ≤ 0.01
      Version
      The relay rejects any DIA-NN outside 2.3; only exactly 2.3.0 is marked "assets verified"

      DDA · Sage 0.14.7

      Search
      Database search against the frozen FASTA (no library)
      Digest
      Trypsin (after K or R, not before P), 1 missed cleavage, peptides 7–30 residues
      Mods
      Carbamidomethyl C fixed; oxidised M variable (up to 2)
      Tolerance
      Precursor ±10 ppm, fragment ±20 ppm
      FDR
      PSM-level only: spectrum q ≤ 0.01. No separate peptide or protein FDR

      What each count means

      DIA · DIA-NN

      Precursors
      Primary. Distinct precursors (modified sequence + charge) at q ≤ 0.01
      Peptides
      Distinct stripped sequences among those precursors
      Proteins
      Protein groups at 1% protein-group FDR among those precursors. Context only

      DDA · Sage

      PSMs
      Primary. Peptide-spectrum matches at 1% PSM FDR
      Peptides
      Distinct peptide sequences, modifications included, among those PSMs
      Proteins
      Distinct protein groups among those PSMs; no separate protein FDR. Context only

      Proteins are never used to rank a run. They carry 20% of the IPS weight.

      IPS: Instrument Performance Score

      IPS places a run's depth against a fixed calibration set for its instrument and SPD: 60 is the median calibration run and 90 its 90th percentile. It weights precursors 50% (PSMs for DDA), peptides 30% and proteins 20%. The calibration set is 352 UC Davis runs from April 2026.

      IPS is not shown on this page yet. A lookup error scores Exploris and timsTOF runs against a pooled all-instrument reference instead of their own, so Exploris scores read too low and timsTOF scores too high. Scores return once they are recomputed.

      Returns with the fix (Decision 2): band labels from docs/ips_metric.md
      90–100Top 10% of the calibration set
      70–89Above the median
      55–69Around the median
      40–54Below the median
      25–39Poor: check column, LC, source and calibration
      0–24Bad: fix before running samples

      The HeLa standard

      Pierce HeLa Protein Digest Standard (Thermo Scientific 88328 / 88329): a tryptic digest of HeLa S3 with more than 15,000 proteins and under 10% missed cleavages. One commercial standard means differences reflect the instrument and LC, not sample prep.

      Buy 20 µg (88328) · Buy 5 × 20 µg (88329)

      Points across peak

      How many MS2 scans sample each precursor's elution peak. STAN's guideline: 12 or more for reliable quantitation, 6–12 acceptable depending on peak shape, under 6 and error grows quickly. At high SPD on short columns, cycle time can exceed peak width.

      Background: Matthews & Hayes, Anal. Chem. 1976, 48, 1375–1382, on how few sampling points bias GC-MS ratio measurements. doi:10.1021/ac50003a028
