# STAN Museum — Deployment Guide

Estimated time: ~10 minutes.

## What this deploys

- `stan/dashboard/public/museum.html` — standalone museum page (no backend needed)
- `historical_bsa_summary.json` — aggregated BSA QC data (generated by `scripts/aggregate_historical_qc.py`)

---

## Step 1: Generate the data JSON

On a machine with Quobyte mounted (or run directly on Hive):

```bash
# On Hive:
python3 scripts/aggregate_historical_qc.py \
    --results-dir /quobyte/proteomics-grp/STAN/historical_bsa/results \
    --out historical_bsa_summary.json \
    --verbose

# Or with Quobyte locally mounted:
python3 scripts/aggregate_historical_qc.py \
    --results-dir /Volumes/proteomics-grp/STAN/historical_bsa/results \
    --out historical_bsa_summary.json \
    --verbose
```

Expected output: `999 records, 270 with PSMs, 277 with coverage`.
The JSON is ~225 KB — safe to commit or upload directly.

---

## Step 2: Upload to HF Space

The museum page is fully self-contained (no STAN API calls). Host it as a static file.

### Option A: Add to the existing `brettsp/stan` HF Space

```bash
# Clone the HF Space repo (requires git-lfs + HF token)
git clone https://huggingface.co/spaces/brettsp/stan stan-hf-space
cd stan-hf-space

# Copy files
cp /path/to/stan/stan/dashboard/public/museum.html .
cp /path/to/historical_bsa_summary.json .

# Update app.py to serve them (add these two routes if not present):
# @app.get("/museum", response_class=FileResponse)
# async def museum(): return "museum.html"
#
# @app.get("/static/historical_bsa_summary.json")
# async def bsa_json(): return FileResponse("historical_bsa_summary.json")

git add museum.html historical_bsa_summary.json app.py
git commit -m "feat: historical MS QC museum page"
git push
```

### Option B: Standalone static Space (simplest)

Create a new HF Space at `brettsp/stan-museum` (type: Static):

```bash
git clone https://huggingface.co/spaces/brettsp/stan-museum stan-museum
cd stan-museum
cp /path/to/museum.html index.html
cp /path/to/historical_bsa_summary.json historical_bsa_summary.json
# Edit museum.html: change MUSEUM_DATA_URL to './historical_bsa_summary.json'
git add . && git commit -m "init museum" && git push
```

The page will be live at `https://brettsp-stan-museum.hf.space`.

## Data notes

- The JSON is generated from Sage v0.14.7 searches against bovine SwissProt (P02769 BSA, 607 AA)
- Coverage uses `spectrum_q ≤ 1%` FDR (PSM-level), matching `psm_summary.txt` counts
- Many early runs (2005-2009) have PSMs from LTQ-tuned Sage params (`psm_ltq.txt`) only —
  the standard high-res params fail on low-resolution LTQ MS2 data
- 997 result directories; 270 have PSMs > 0; 277 have sequence coverage data
- Michrom-era files (5 runs, ~2008) produce 0 PSMs with modern parameters —
  this is historically accurate, not a bug

## Re-running the aggregator

The script is idempotent. Re-run it any time new historical searches are added:

```bash
python3 scripts/aggregate_historical_qc.py --verbose
```

Then re-upload `historical_bsa_summary.json` to the HF Space.
